A make.fun bounty entry for **One Word From Your Ex**: one word an ex would use to describe the entrant.

## The entry

**Exhausting** — the word every ex reaches for eventually, and the one the entrant knows is true.

## How it works

`main.py` (Python standard library only) writes that single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`, exactly 10 characters, no trailing newline. It writes nothing anywhere else.

Run it with:

```sh
python3 main.py
```
